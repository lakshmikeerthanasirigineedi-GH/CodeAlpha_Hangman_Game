# Hangman Game using Python

## 📌 About The Project
This is a simple Hangman Game developed using Python as part of my Python Programming Internship at CodeAlpha.

The game randomly selects a word, and the player must guess the word letter by letter before losing all lives ❤️.

---

## 🚀 Features
- Random word selection
- Heart-based lives system ❤️
- Interactive gameplay
- Python loops and conditions
- User-friendly terminal interface
